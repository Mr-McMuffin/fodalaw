# Foda Law

Single-page site for Foda Law — criminal defence lawyers, Toronto.

Static site, no build step. Entry point: `index.html`.

- `index.html` — the site (Home · Practice · Approach · Contact, no-scroll paging)
- `logo_t.png` — transparent brand wordmark (header / preloader)
- `icon.png` — the FZ monogram mark
- `logo.png` — full brand logo (source asset)
